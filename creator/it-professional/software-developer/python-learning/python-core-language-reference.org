#+TITLE: Python Core Language Reference Checklist

#+begin_quote
  *Scope Note*: This checklist provides an exhaustive reference of all core language syntax,
  semantics, data model components, execution mechanics, keywords, operators, and dunder methods
  in *Python 3* (up to Python 3.12+). Built-in standard library modules (such as =sys=, =os=,
  =collections=, =itertools=, =asyncio=, =math=) are intentionally excluded to focus strictly on core
  language elements and runtime primitives.
#+end_quote

* 1. Lexical Structure & Basic Syntax

** 1.1 Comments & Docstrings
- Inline Comments
  - Syntax: =# Comment text=
- Block Comments
  - Multi-line sequential =#= lines
- Module Docstrings
  - Top-of-file =""" Module documentation """= or =''' Module documentation '''=
- Class Docstrings
  - Under class header =""" Class documentation """=
- Function and Method Docstrings
  - Under function header =""" Function documentation """=

** 1.2 Identifiers & Naming Rules
- Variable Naming Rules
  - Case-sensitivity (=var= vs =Var=)
  - Unicode Identifiers support (PEP 3131)
  - Single Leading Underscore (=_variable= convention for internal/private)
  - Single Trailing Underscore (=variable_= convention to avoid keyword collisions)
  - Double Leading Underscore (=__variable= name mangling inside class context)
  - Double Leading and Trailing Underscores (=__variable__= reserved system/dunder names)

** 1.4 Literals
- Integer Literals
  - Decimal Literals (=0=, =123=, =1_000_000=)
  - Binary Literals (=0b1010=, =0B1010=)
  - Octal Literals (=0o755=, =0O755=)
  - Hexadecimal Literals (=0xFF=, =0XFF=)
  - Underscore Digit Separators (=1_000_000=, =0x_FF_FF=)
- Floating-Point Literals
  - Point Float (=3.14=, =.5=, =10.=)
  - Exponent Float (=1e-5=, =2.5E+10=, =1_000.000_1=)
- Imaginary / Complex Literals
  - Imaginary Integers and Floats (=3j=, =4.2J=, =1e-3j=)
- String Literals
  - Single-Quoted Strings (='text'=)
  - Double-Quoted Strings (="text"=)
  - Triple-Quoted Multiline Strings (='''text'''=, ="""text"""=)
  - Raw Strings (=r"raw\text"=, =R"raw\text"=)
  - Byte Strings (=b"bytes"=, =B"bytes"=, =br"rawbytes"=, =rb"rawbytes"=)
  - Formatted String Literals / F-Strings (=f"val={x}"=, =F"val={x}"=, =fr"text"=, =rf"text"=)
    - F-string self-documenting debugging syntax (=f"{x=}"=)
    - F-string format specifiers (=f"{val:.2f}"=, =f"{val:>10}"=)
    - F-string conversion flags (=!r= for repr, =!s= for str, =!a= for ascii)
    - Nested F-strings and arbitrary quote re-use (Python 3.12+)
- Escape Sequences (Exhaustive List)
  - =\\= (Backslash)
  - =\'= (Single Quote)
  - =\"= (Double Quote)
  - =\a= (ASCII Bell)
  - =\b= (ASCII Backspace)
  - =\f= (ASCII Formfeed)
  - =\n= (ASCII Linefeed)
  - =\r= (ASCII Carriage Return)
  - =\t= (ASCII Horizontal Tab)
  - =\v= (ASCII Vertical Tab)
  - =\ooo= (Character with octal value ooo)
  - =\xhh= (Character with hex value hh)
  - =\N{name}= (Character named name in Unicode database)
  - =\uxxxx= (Character with 16-bit hex value xxxx)
  - =\Uxxxxxxxx= (Character with 32-bit hex value xxxxxxxx)
- Special Constants
  - True
  - False
  - None
  - Ellipsis (=...=)

** 1.5 Line Structure & Indentation
- Off-Side Rule (4-space indentation standard)
- Explicit Line Continuation Backslash (=\=)
- Implicit Line Continuation Inside Parentheses =()=, Brackets =[]=, and Braces ={ philosophy}=
- Compound Statements on Single Line Semicolon Separator (=;=)

** 1.6 Statements vs. Expressions
- Expressions (Evaluates to a concrete value)

* 2. Core Built-in Data Types

** 2.1 Numeric Types
- int (Arbitrary precision integer)
- float (IEEE 754 double precision floating point)
- complex (Complex number with real and imag floating point parts)
- bool (Boolean subtype of int: True and False)

** 2.2 Sequence Types
- str (Immutable sequence of Unicode code points)
- list (Mutable dynamic array of heterogeneous elements)
- tuple (Immutable sequence of heterogeneous elements)
- range (Immutable sequence of numbers generated on demand)
- bytes (Immutable sequence of single bytes in range 0 <= x < 256)
- bytearray (Mutable sequence of single bytes in range 0 <= x < 256)
- memoryview (Buffer protocol interface for shared memory access without copying)

** 2.3 Set Types
- set (Mutable unordered collection of unique hashable elements)
- frozenset (Immutable hashable set)

** 2.4 Mapping Types
- dict (Mutable key-value mapping with guaranteed insertion-order preservation)

** 2.5 Special Runtime Types & Constants
- NoneType (Singleton object None representing absence of value)
- EllipsisType (Singleton object Ellipsis / ... used in slicing and type placeholders)
- NotImplementedType (Singleton object NotImplemented returned by binary methods)
